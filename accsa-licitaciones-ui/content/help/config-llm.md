En **Configuración › Configuración LLM** (solo administradores) se elige el modelo
de IA que usarán los análisis:

- **Modelo principal**: **Gemini** (Google) u **OpenAI** (GPT).
- **Nivel de inteligencia**:
  - **Bajo**: más rápido y económico.
  - **Medio**: equilibrio entre velocidad y calidad.
  - **Alto**: más capaz, pero más lento.

Es una **configuración global**. Aplica a los análisis que se **creen a partir de
ese momento**; los análisis en curso o ya existentes conservan el modelo con el
que fueron creados (por eso el detalle de cada análisis muestra su propio modelo y
nivel).

Pulse **Guardar** para aplicar los cambios.
