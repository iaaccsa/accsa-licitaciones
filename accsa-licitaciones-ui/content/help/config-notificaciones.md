En **Configuración › Notificaciones** (solo administradores) hay un **interruptor
global** para los correos de notificación del sistema.

- **Activado**: el sistema envía los correos de aviso.
- **Desactivado**: no se envía **ningún** correo.

Aplica a **todos** los análisis. Úselo, por ejemplo, para silenciar los avisos
durante pruebas o mantenimiento.
