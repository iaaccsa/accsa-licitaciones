El proyecto no tiene tags de git ni releases publicados. Todo el historial está en una sola rama `main`.

**Why:** Es un proyecto relativamente nuevo (inició 2026-01-29), aún no ha llegado a un release formal.

**How to apply:** Todos los cambios nuevos van en la sección `[Unreleased]` hasta que se defina una primera versión. El remote es `git@github-accsa:iaaccsa/accsa-licitaciones-ui.git` (org: iaaccsa). Las entradas del changelog se escriben en español, verbos en infinitivo.
